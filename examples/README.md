# Example configuration

These files show the shape of the community configuration contracts. A real
instance keeps its own copies in the private `community` repository under
`config/`, pointed at by `COMMUNITY_REPO_PATH`.

- `discord.example.yaml` - desired Discord roles/categories/channels
- `sources.example.yaml` - news sources
- `watchlists.example.yaml` - curated Berkeley / OSS watchlist
- `policy.example.yaml` - operational choices
